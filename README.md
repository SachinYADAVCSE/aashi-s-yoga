# Aashi's Yog & Fitness Studio — React + Tailwind v4 (Notion Design System)

A modern, high-performance React application built with **Vite**, **Tailwind CSS v4**, and **Lucide Icons**, implementing the **Notion — Warm Paper Notebook Under Afternoon Sun** Design System.

---

## 🎨 Notion Design Tokens Implemented

- **Page Canvas**: Warm Paper `#f6f5f4` (`--color-paper-warmth`).
- **Cards**: Pure White `#ffffff` with 1px hairline border (`border-black/8`), 12px rounded corners (`rounded-xl`), no shadows on content cards.
- **Primary CTA**: Notion Blue `#0075de` (`text-white`, `rounded-[8px]`, `px-[15px] py-[6px]`).
- **Ghost CTA**: Sky Tint `#e6f3fe` background with `#0075de` text.
- **Hero Highlight Pill**: Embedded Marigold `#ffb110` / Peach `#f6d5b8` pill wrapping keywords.
- **Avatar Character Marks**: Horizontal row of 7 round character avatars in 2px colored borders (`#097fe8`, `#f64932`, `#ffb110`).
- **Editorial Typography**: Lyon Text / Source Serif 4 pull-quotes paired with Inter sans-serif display headlines.
- **Accent Feature Cards**: Marigold `#ffb110`, Coral `#f64932`, Sky Wash `#62aef0`, and Dark Feature Card (`#02093a` Midnight Ink).

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

---

## ⚡ How to Deploy to Vercel

### Option A: Using Vercel CLI
```bash
npx vercel
```

### Option B: Deploy via GitHub / Vercel Dashboard
1. Push this folder to a GitHub repository.
2. Import the project into your Vercel Dashboard.
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**!
